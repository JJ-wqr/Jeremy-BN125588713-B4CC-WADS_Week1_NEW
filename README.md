Security protocols on WEB has trasitioned from TLS 1.2 to TLS 1.3. This shift has made countless websites vulnerable to attack. TLS 1.3 has been known to fix flaws of the earlier security protocol version - specifically protection from weak encryption methods, downgrade attack (Aladi, 2024). This is done by the removal of outdated features from the WEB, speeding up the connection, and providing stronger encryption. However, 77% of WEB traffic still persist in using older TLS versions that lack protection by the modern protocols - where Man-in-the-Middle (MITM) attacks are prone to happening and hackers can intercept or alter data (Aladi, 2024).

    In addition, the poor management of X.509 users exacerbate this issue. Utilizing self-signed, expired, or long-lived certificates breaks this trust as well as secure connections (Aladi, 2024). This is dire as hackers can impersonate legitimate services and steal sensitive information. 

    There are 3 effective WEB security strategies, including: etiological, smpytomatic, and hybrid approach. WAFS (Web Application FIrewalls) with ModSecurity, high-precision input filtering based on OWASP Stinger, etc. have detection accuracy as 98.9% (Aladi, 2024). SQLCheck, Amnesia, and libAnomaly are effective against code injection security-risks (Aladi, 2024).
